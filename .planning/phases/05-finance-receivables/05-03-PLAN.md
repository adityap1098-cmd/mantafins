  <action>
    Create `manta-finance/app/api/receivables/payment/route.ts` with POST handler.

    Auth check. Body: `{ saleId: string, amount: number, note?: string }`.

    Validation:
    - `saleId` required string
    - `amount` must be a positive number
    - Fetch the sale: `prisma.sale.findUnique({ where: { id: saleId } })`
    - If not found → 404
    - If `amount > sale.balance` → 400 with `{ error: 'Jumlah pembayaran melebihi sisa piutang' }`

    In a Prisma transaction (`prisma.$transaction`):
    1. Compute new values:
       - `newPaid = sale.paid + amount`
       - `newBalance = sale.balance - amount`
       - `newStatus = newBalance <= 0 ? 'Terbayar' : sale.status`
    2. Update sale: `prisma.sale.update({ where: { id: saleId }, data: { paid: newPaid, balance: newBalance, status: newStatus } })`
    3. Create PaymentLog: `prisma.paymentLog.create({ data: { saleId, refNo: sale.refNo, customer: sale.customer, amount, date: new Date(), note: note ?? null } })`

    Return 201: `{ success: true, saleId, newPaid, newBalance, newStatus }`.

    Use immutable pattern — compute new values, pass to update, do not mutate the fetched sale object.
