<task type="auto">
  <name>Task 1: Create GET /api/finance route</name>
  <files>manta-finance/app/api/finance/route.ts</files>
  <action>
    Create `manta-finance/app/api/finance/route.ts` with a GET handler.

    Requires `periodId` query param (400 if missing). Auth check using the standard cookie pattern.

    Query: fetch all Sales with items included for the period. Fetch all OperationalCosts for the period.

    **Compute FinanceSummary (P&L):**
    - `totalPendapatan` = sum of sale.grandTotal
    - `totalHpp` = sum of SaleItem.totalHpp per sale
    - `labaKotor` = totalPendapatan - totalHpp
    - `totalDiskon` = sum of (sum(item.hargaUnit*item.qty) - sale.grandTotal) per sale
    - `totalBiayaOperasional` = sum of operationalCosts[].amount
    - `labaBersih` = labaKotor - totalBiayaOperasional
    - `marginKotor` = labaKotor / totalPendapatan * 100 (0 if no revenue)
    - `marginBersih` = labaBersih / totalPendapatan * 100 (0 if no revenue)
    - `totalPiutang` = sum of sale.balance where sale.status !== 'Terbayar'
    - `totalTerbayar` = sum of sale.paid
    `operationalCosts` array = operationalCosts records mapped to `{ id, description, amount }`

    **Compute ProductMarginRow[] (for FIN-02):**
    Group SaleItems by productName. For each product:
    - `productName`: string
    - `sku`: string
    - `totalQty`: number — total units sold
    - `hppUnit`: number — first found hppUnit (consistent per product snapshot)
    - `avgHargaAktual`: number — weighted average: sum(totalHarga) / sum(qty)
    - `totalLabaKotor`: number — sum(totalHarga) - sum(totalHpp)
    - `marginPersen`: number — totalLabaKotor / sum(totalHarga) * 100

    **Compute CustomerDiscountRow[] (for FIN-04):**
    Group Sales by customer. For each customer:
    - `customer`: string
    - `totalTransaksi`: number — count of sales
    - `totalPenjualan`: number — sum of grandTotal
    - `totalDiskon`: number — sum of discounts
    - `avgDiskonPersen`: number — (totalDiskon / (totalPenjualan + totalDiskon)) * 100

    Return:
    ```typescript
    { summary: FinanceSummary, productMargins: ProductMarginRow[], customerDiscounts: CustomerDiscountRow[] }
    ```

    All arithmetic uses round2 pattern (Math.round(x*100)/100).
