    - GET /api/dashboard?periodId=nonexistent → 200 JSON with empty summary (zero values) and empty arrays
    - GET /api/dashboard?periodId=valid → 200 JSON with DashboardData shape
    - salesByCustomer array items have { customer: string, total: number } sorted by total desc
    - salesByCategory array items have { category: string, total: number } — joins Sale → SaleItem → ProductSnapshot via periodId+sku
    - topProducts array items have { productName: string, qty: number } top 10 by qty desc
    - summary uses computePeriodSummary() from lib/calculator/margin.ts
  </behavior>
  <action>
    Create `manta-finance/app/api/dashboard/route.ts` as a Next.js App Router route handler.

    Auth pattern (identical to existing routes): extract `SESSION_COOKIE_NAME` cookie from `req.cookies.get(SESSION_COOKIE_NAME)?.value`, call `validateSession(token)`, return NextResponse.json({ error: "Unauthorized" }, { status: 401 }) if invalid.

    Query logic:
    1. Extract `periodId` from `req.nextUrl.searchParams.get('periodId')` — return 400 if missing.
    2. Fetch all sales for the period with items included:
       ```
       prisma.sale.findMany({
         where: { periodId },
         include: { items: true },
       })
       ```
    3. Build `PeriodTransactionInput[]` for computePeriodSummary by computing metrics per sale using `computeTransactionMetrics({ grandTotal: sale.grandTotal, items: sale.items.map(i => ({ hppUnit: i.hppUnit, hargaUnit: i.hargaUnit, qty: i.qty })) })`.
    4. Compute `summary = computePeriodSummary(txInputs)`.
    5. Build `salesByCustomer`: group sales by `sale.customer`, sum `grandTotal`. Sort descending by total. Shape: `{ customer: string; total: number }[]`.
    6. Build `salesByCategory`: fetch ProductSnapshots for the period (`prisma.productSnapshot.findMany({ where: { periodId } })`), build a Map of sku → category. For each SaleItem, look up category. Group by category, sum `totalHarga`. Sort descending. Shape: `{ category: string; total: number }[]`.
    7. Build `topProducts`: group SaleItems by `productName`, sum `qty`. Sort descending, take first 10. Shape: `{ productName: string; qty: number }[]`.
    8. Return `NextResponse.json({ summary, salesByCustomer, salesByCategory, topProducts })`.

    Export the response type as `DashboardData` interface at the top of the file so the UI can import it.

    Do NOT use `any` types. Immutable pattern: build new arrays via map/reduce, do not mutate.
