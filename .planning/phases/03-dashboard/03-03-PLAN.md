  <action>
    First, install Recharts:
    ```bash
    cd manta-finance && npm install recharts
    ```

    Then create the three chart components. All are `'use client'` (Recharts requires browser).

    ---

    **SalesBarChart.tsx** — Bar chart: penjualan per konsumen.

    Props: `{ data: { customer: string; total: number }[]; loading: boolean }`.

    Use Recharts `ResponsiveContainer` (width="100%" height={300}) wrapping a `BarChart` with `data` prop.
    - `XAxis dataKey="customer"` — tick fontSize 11, angle -30, textAnchor="end", height 60 to prevent label cutoff
    - `YAxis` — tickFormatter formats as abbreviated Rupiah: `(v) => 'Rp ' + (v >= 1_000_000 ? (v/1_000_000).toFixed(1)+'Jt' : (v/1_000).toFixed(0)+'Rb')`
    - `CartesianGrid strokeDasharray="3 3" stroke="#f0f0f0"`
    - `Tooltip` — formatter: `(value: number) => [new Intl.NumberFormat('id-ID', { style: 'currency', currency: 'IDR', minimumFractionDigits: 0 }).format(value), 'Penjualan']`
    - `Bar dataKey="total" fill="#3b82f6" radius={[4,4,0,0]}`

    Wrap in `<div className="bg-white rounded-lg border border-gray-200 p-4 shadow-sm">` with `<h3 className="text-sm font-semibold text-gray-700 mb-3">Penjualan per Konsumen</h3>`.

    When `loading=true`: show `<div className="animate-pulse bg-gray-100 rounded h-64" />`.
    When `data.length === 0` and not loading: show `<div className="h-64 flex items-center justify-center text-gray-400 text-sm">Tidak ada data penjualan</div>`.

    ---

    **CategoryPieChart.tsx** — Pie chart: komposisi per kategori.

    Props: `{ data: { category: string; total: number }[]; loading: boolean }`.

    Use `ResponsiveContainer` (width="100%" height={300}) wrapping `PieChart`.
    - `Pie data={data} dataKey="total" nameKey="category" cx="50%" cy="50%" outerRadius={100} label={({ category, percent }) => `${category} ${(percent * 100).toFixed(1)}%`}` — labelLine={false} for labels inside
    - Color each segment with `Cell` using a fixed palette: `['#3b82f6','#10b981','#f59e0b','#ef4444','#8b5cf6','#06b6d4','#f97316','#ec4899']` cycling via index % palette.length
    - `Tooltip formatter={(value: number) => new Intl.NumberFormat('id-ID', { style: 'currency', currency: 'IDR', minimumFractionDigits: 0 }).format(value)}`
    - `Legend` — iconType="circle" iconSize={10}

    Wrap in `<div className="bg-white rounded-lg border border-gray-200 p-4 shadow-sm">` with title "Komposisi Penjualan per Kategori".

    Same loading skeleton and empty-state as SalesBarChart.

    ---

    **TopProductsChart.tsx** — Horizontal bar chart: top 10 produk terlaris by qty.

    Props: `{ data: { productName: string; qty: number }[]; loading: boolean }`.

    Use `ResponsiveContainer` (width="100%" height={Math.max(300, data.length * 40)}) wrapping a `BarChart layout="vertical"` with `data`.
    - `XAxis type="number"` — tick fontSize 11
    - `YAxis type="category" dataKey="productName"` — width=180, tick fontSize 11 (product names can be long)
    - `CartesianGrid strokeDasharray="3 3" stroke="#f0f0f0"`
    - `Tooltip formatter={(value: number) => [value + ' pcs', 'Qty']}`
    - `Bar dataKey="qty" fill="#10b981" radius={[0,4,4,0]}`

    Title: "Top 10 Produk Terlaris (by Qty)".

    Same loading/empty-state pattern.
